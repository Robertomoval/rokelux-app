Preguntas frecuentes

Información clara antes de coordinar.

Cuéntanos tu necesidad y te ayudaremos a definir el siguiente paso.

¿Qué información envío para cotizar?

Indica la ciudad, el tipo de espacio, la plaga observada y, si lo sabes, el área aproximada. Con eso podremos orientarte y coordinar una evaluación cuando sea necesaria.

¿En qué ciudades atiende ROKELUX?

La cobertura publicada incluye Samborondón, Guayaquil, Lago Agrio, Santo Domingo y Francisco de Orellana. Confirma disponibilidad y fechas al solicitar el servicio.

¿Cómo se calcula el valor del servicio?

Depende del tipo de plaga, el espacio, el área y el alcance requerido. Solicita una cotización para recibir una propuesta según tu caso.

¿El informe incluye el mapa de estaciones?

Cuando el cliente cuenta con estaciones y un mapa cargado, el informe puede mostrar el mapa y el estado individual de cada punto. Si no hay estaciones, esto no impide generar el informe.
